# Java
Java is a compiled, object-oriented programming language designed to be portable, secure, and robust in distributed environments. Because it runs on the Java Virtual Machine (JVM), it enables the development of scalable, cross-platform applications and is widely used in backend systems, enterprise applications, and mobile development. 

## History
Java was developed in the 1990s by Sun Microsystems, led by James Gosling, with the goal of creating a portable language that could run on any device based on the “write once, run anywhere” philosophy. Officially launched in 1995, Java quickly established itself in the development of enterprise applications and distributed systems, and following Oracle’s acquisition of Sun, it has continued to evolve with improvements in performance, concurrency, and support for new architectures, remaining one of the most relevant languages in backend and mobile development.

# C++
C++ is a compiled, multi-paradigm, system-oriented programming language designed to provide direct control over hardware resources, memory and performance, whilst maintaining abstraction capabilities through object-oriented and generic programming. Its execution model, which is closely integrated with the operating system, makes it a suitable tool for high-performance software, critical infrastructure, real-time execution engines and components where efficiency and deterministic control are paramount. 


## History
C++ was developed in the early 1980s by Bjarne Stroustrup at Bell Labs as an extension of the C language, initially under the name “C with Classes”, with the aim of introducing support for object-oriented programming without sacrificing the performance of the base language. Over time, it evolved into a standardised independent language, incorporating features such as templates, exceptions and the Standard Template Library (STL), and has continued to evolve through modern standards such as C++11, C++14, C++17 and C++20, which have significantly expanded its capabilities in concurrency, expressiveness and abstraction without losing its fundamental focus on performance and low-level control.

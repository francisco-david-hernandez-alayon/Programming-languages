# C
C is a compiled, structured, general-purpose programming language designed to provide efficient and direct control over memory, hardware and system resources, whilst maintaining a minimalist syntax and a limited set of abstractions. Its low-level model makes it an essential tool for developing operating systems, drivers, embedded software and critical components where performance and close integration with the hardware are paramount. 

## History
C was developed in the early 1970s at Bell Labs by Dennis Ritchie as an evolution of the B language, with the aim of creating an efficient and portable language for implementing the UNIX operating system. Its design focused on simplicity, performance and hardware independence, which enabled its rapid adoption in operating systems and low-level software, establishing it as one of the most influential languages in the history of programming and the basis for numerous subsequent languages such as C++, Java and C#.
